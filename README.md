# Vacation App 👋

Esta aplicación móvil es un ejemplo desarrollado basado en el diseño de Figma disponible en: [GT - Application for Vacation - Traveling - Destination](https://www.figma.com/community/file/1062262274514482112/gt-application-for-vacation-traveling-destination).

Ayuda a los usuarios a descubrir y planificar sus vacaciones soñadas, explorando destinos populares y lugares cercanos.
